支持搜索结果页、列表页、文章页；脚本在线时走脚本解析，未装脚本时浏览器本地解析，结果同样进下方列表与知识库。
流程：搜索词队列 → 按所选接口逐个生成搜索结果页地址 → 脚本后台抓取源码 → 先按 article / main / #content / .post-body 等优先级挑出正文根区域（去掉导航、页脚噪声）→ 在根区域内遍历 a[href] 得到 { text, href } 链接清单，并用 class 定位的文章列表节点补全标题 → 汇总去重后写入知识库。
多个搜索词会串行请求，词与词之间随机降频 1.2–2.6 秒；单个词失败不影响其余词，最后统一汇总。
采集结果默认自动写入第 3 页「知识库」，也可关掉开关后用结果列表下方按钮手动挑选。
被风控了怎么办？脚本会先预热搜索引擎首页拿会话 Cookie、带浏览器请求头、失败随机退避重试一次； 一旦识别出验证码 / 安全验证 / 429 限流等风控页会立即停止并明确提示（不硬试，避免封 IP）， 此时换「必应 / 360」接口重试，或用下面第 3 个入口粘贴源码离线解析（不走网络，不受风控影响）。
